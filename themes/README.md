# Thèmes du tableau de bord ioDek

Bientôt : les thèmes de couleurs du tableau de bord ioDek (écran de la Tesla), au format CSS, à importer dans ioDek depuis le mode modification du tableau de bord.

Le format, la liste des variables et la marche à suivre pour proposer un thème arriveront ici avec la prochaine version d'ioDek.
